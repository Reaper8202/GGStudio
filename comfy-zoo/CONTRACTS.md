# Comfy Zoo — Build Contracts (read before writing any code)

This file is the coordination contract between parallel agents. **Do not edit files outside
your ownership zone. Do not edit this file, `src/core/EventBus.ts`, `src/data/*`, or
`src/platform/PlatformAdapter.ts` — they are the shared contract.**

## Ownership zones

| Agent | Owns (create/edit freely) |
|---|---|
| pipeline | `package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`, `scripts/`, `public/assets/` |
| core | `src/main.ts`, `src/core/` (except `EventBus.ts`), `src/world/`, `src/entities/`, `src/systems/`, `src/platform/` (implementations only) |
| ui | `src/ui/` only |

## Fixed decisions (do not revisit)

- **Stack**: Three.js + TypeScript + Vite. Runtime deps: `three` ONLY. Dev deps managed by
  pipeline agent. Core/UI agents must NOT modify `package.json` — if you believe you need a
  dependency, you don't; use `three` or the DOM.
- **Audio**: raw WebAudio (no Howler). UI SFX files live at `assets/audio/ui/<file>.ogg`
  (paths in manifest). Core exposes nothing for audio; UI owns SFX playback via a tiny
  `src/ui/Sfx.ts`.
- **Player model**: NO downloaded model. The player is a small rounded "ranch keeper" built
  from Three.js primitives (capsule body, sphere head, cone hat) vertex-colored with the
  palette below. Zero asset weight.
- **UI is HTML/CSS DOM overlay**, never canvas text. UI mounts into `#ui-root`. The 3D canvas
  is `#game-canvas`. Both exist in `index.html` (pipeline agent creates it exactly so).
- **No physics engine.** Circle-vs-circle / circle-vs-AABB on a spatial hash (core owns).
- All tuning constants live in `src/data/*.json` — never hardcode a number that a designer
  would want to tune.
- **Systems ↔ UI communicate ONLY via the typed `EventBus`** (`src/core/EventBus.ts`).
  UI never imports from `src/entities` or `src/systems`; core never imports from `src/ui`.
  `src/main.ts` (core agent) is the only composition point: it instantiates `Game` and calls
  `mountUI(bus, adapter, gameQuery)` exported from `src/ui/index.ts`.
- **`GameQuery`** (read-only view interface for UI, defined in `EventBus.ts`): UI may poll it
  for render-time data (coins, quest state, zoopedia entries, build catalog, shelter occupancy).
  Core implements it.

## Asset paths (deterministic — code against these before assets exist)

- Models: `assets/models/animals/<Id>.glb` (e.g. `Cow.glb`, `Horse_White.glb`),
  `assets/models/dinos/<Id>.glb` (e.g. `Trex.glb`),
  `assets/models/buildings/<Id>.glb` (e.g. `SmallBarn.glb`),
  `assets/models/nature/<Id>.glb` (e.g. `BirchTree_1.glb`, `Grass_Small.glb`, `Rock_1.glb`)
- Audio: `assets/audio/ui/<original OGG filename>`
- Icons: `assets/icons/<Name>.svg` (white silhouette set; tint via CSS `mask-image`)
- Fonts: `assets/fonts/LilitaOne.woff2`, `assets/fonts/Yuyu.woff2`
- Manifest: `assets/manifest.json` — shape:
  ```json
  { "phases": { "boot": ["models/animals/Cow.glb", ...],
                "main": [...], "dinos": [...] },
    "files": { "models/animals/Cow.glb": { "bytes": 12345 } } }
  ```
- Animation clips in packs have inconsistent names. `AssetManager` (core) resolves clips by
  case-insensitive substring: prefer `idle`, `walk`, `run`, `eat`, falling back to clip 0.

## Design tokens (UI agent: put these in `src/ui/theme.css` as CSS custom properties)

cream `#F6EEDD` · bark `#8A6B4D` · leaf `#7FB069` · sky `#9BC8E3` · peach `#F2A65A` ·
muted red `#C96F6F` (only for "can't afford" shake). Radii 16–24px, 2px bark outlines,
no gradients, no pure black/white. Fonts: Lilita One (interactive), Yuyu (flavor).
Motion: 150–250ms scale-pop, spring easing. Safe-area: `env(safe-area-inset-*)`.
